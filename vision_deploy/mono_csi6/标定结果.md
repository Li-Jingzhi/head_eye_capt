## 复现

在项目根目录执行，指定一个不存在的输出文件：

```bash
/usr/bin/python3 portable_stereo_fisheye_calibration/calibrate_mono_orin_pro.py \
  --fit-only --images data/mono_csi6_chessboard_20261021_144426 \
  --output /tmp/mono_csi6_reproduced_fisheye.json
```

原始图像保留本机data目录，默认不纳入Git；参数JSON保存输入图像哈希和逐图误差。[采集及恢复操作](标定采集流程.md)。
