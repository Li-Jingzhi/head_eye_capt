## 采集质量与范围

- 相机坐标覆盖范围约336×234×231mm，Z=0.301–0.531m。
- 7100帧源时差P95=9.099ms、最大9.975ms；到达时差P95=8.279ms、最大9.997ms。
- 校正极线纵差绝对值P95=0.177px；重投影误差P95=0.0885px。
- 每点视差抖动P95的最大值0.0936px；最大关节窗口变化0.000672°。
- 各位置XYZ帧内抖动P95的中位数0.229mm、95分位0.565mm、最差位置1.053mm。增加同一点帧数主要降低随机波动，不能保证消除系统偏差。

当前误差Z分量较大，但仅凭本次数据不能区分相机残余畸变、球实际尺寸、MDH/装配误差等贡献。建议实测球径/偏置，在更多空间位置与不同姿态采独立第二批，先用本次模型做不重新拟合的误差检查，再决定相机重标定或MDH修正；不靠删点宣称达标。硬件曝光同步仍未验证，球直径40mm为假设。

## 复现

在仓库根目录执行（output需为不存在的新文件）：

```bash
/usr/bin/python3 -m interactive_ball_calibration.pro_fit \
  --capture datasets/drag_replay_20261019_191653_275606/replay_capture.jsonl.gz \
  --output configs/orin_pro_ball_registration_reproduced.json
```

程序校验配置哈希、设备身份、每帧质量及双时差、源帧唯一性、历史采样时效，并从全部逐帧数据重算50帧融合和MDH FK，与已保存结果对照。完整时间、抖动检查见同目录`capture_quality.json`。归档清单及压缩前后哈希见数据目录`manifest.json`。

验证：3项新拟合测试、13项采集回归测试、编译检查通过；使用归档数据重新运行得到完全一致的JSON结果。
